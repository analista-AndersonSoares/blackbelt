# 🥋 Portfólio Lean Six Sigma Black Belt - Metodologia DMAIC

Este repositório contém uma aplicação web interativa desenvolvida em Python (Streamlit) com o objetivo de documentar e demonstrar a evolução técnica durante a certificação Lean Six Sigma Black Belt. O projeto une a experiência operacional na indústria com ferramentas avançadas de análise de dados.

## 🎯 Objetivo
Transformar as análises estatísticas e a gestão de qualidade num formato visual e estruturado, registando a aplicação prática da metodologia DMAIC na resolução de problemas complexos e na otimização de processos industriais e de negócio.

## ⚙️ Estrutura do Projeto (Fases DMAIC)
A aplicação está dividida de acordo com as fases da metodologia Lean Six Sigma:
* **Define:** Mapeamento de processos (SIPOC), desdobramento de métricas (Árvore CTC) e elaboração de contratos de melhoria.
* **Measure:** Análise de estabilidade, recolha de dados e avaliação da capabilidade do processo (Cp, Cpk).
* **Analyze:** Testes de hipóteses, ANOVA e regressão múltipla para identificação de causas-raiz.
* **Improve:** Planeamento de Experiências (DoE) e análise de correlações para otimização de parâmetros.
* **Control:** Cartas de controlo (CEP) e padronização para garantir a sustentabilidade das melhorias.

## 🛠️ Tecnologias Utilizadas
* **Interface e Web App:** `Streamlit`
* **Manipulação de Dados:** `Pandas`, `NumPy`
* **Análise Estatística:** `SciPy`, `Statsmodels`
* **Visualização de Dados:** `Plotly`, `Matplotlib`, `Seaborn`
